# Contributing / Codex Workflow

Use the work orders. Do not implement ad hoc features.

1. Read `AGENTS.md`.
2. Pick the first incomplete work order.
3. Implement only the scoped behavior.
4. Run relevant tests.
5. Update `RUN_LOG.md`, `repo_status.json`, and `SPEC_GAPS.md`.
6. Stop only at checkpoint gates or blockers.
