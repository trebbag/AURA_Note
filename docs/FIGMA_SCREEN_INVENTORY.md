## Modal, Drawer, Banner, And Toast Inventory

- Low-confidence diagnosis override modal: warning, supporting evidence, missing evidence, add as differential, cancel, override with reason.
- Recording exception approval modal: timer/documentation allowed without implying normal recording.
- Compliance hard-block drawer: blocks finalization-facing actions while blockers remain open.
- History Gap drawer: question, MA follow-up task creation, blocker indicator.
- Transcript drawer: role-limited visibility, correction history, source/confidence metadata, read-only finalized view.
- Finalization confirmations: approve final note, approve patient summary, billing attest, sign/dispatch.
- Export and secure download status toast/banner: storage metadata, short-lived token metadata, failed/expired/wrong-tenant denial.
- EHR writeback banner: disabled, queued, retrying, dead-letter, reconciled, failed publication.
- ClinicOS mode banner: standalone, integrated, unavailable, degraded, stale mapping, permission-denied.
- AI governance banner: live AI disabled, mock/deterministic eval, unsafe output rejected, no raw PHI to external AI.
- Commercial readiness banner: production launch not approved and live vendors disabled.
